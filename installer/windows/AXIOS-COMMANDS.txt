AXIOS
Windows Investigation Platform

COMMAND REFERENCE

Run commands from the extracted AXIOS package directory.

BEFORE THE FIRST AXIOS COMMAND IN A NEW POWERSHELL WINDOW
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

This applies only to the current PowerShell process. It does not change
Windows settings. Then run the normal AXIOS commands below.

1. USER
.\axios.ps1 -Mode User

2. ADMINISTRATOR
.\axios.ps1 -Mode Administrator

3. NETWORK
.\axios.ps1 -Mode Network

Network branches:
overview, services, connections, routing, dns, firewall, wifi,
targeted, full

4. SYSTEM
.\axios.ps1 -Mode System

System branches:
overview, quick, context

5. PERSISTENCE
.\axios.ps1 -Mode Persistence

6. SOFTWARE
.\axios.ps1 -Mode Software

7. RESULTS
.\axios.ps1 -Mode Results

8. HELP
.\axios.ps1 -Mode Help

SYSTEM BRANCHES

Quick system assessment:
  .\axios.ps1 -Mode System -SystemFocus quick

System context assessment:
  .\axios.ps1 -Mode System -SystemFocus context
